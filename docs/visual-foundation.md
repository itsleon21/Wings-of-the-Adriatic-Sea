# 港口近景样板

本轮把 FableFlight 源码对照中最直接的缺口落到本地游戏。它是第一轮基础样板；全群岛地形重塑、全机型座舱重建和渲染管线升级尚未完成。

## 已实现

- 地表共用岩石、草地泥土、沙地及 90m 岩土扫描图集。颜色与扫描的低频照明分离；法线、粗糙度、混合高度参与光照。岩面约 1.5m、草地约 1m 重复尺度；细节随观察距离淡出，雨后与湿岸降低粗糙度。
- 两张 1024² 图集，约 2.81MiB 下载、10.7MiB 纹理显存（含 mip）。环绕留边与连续 UV 导数降低细纹接缝；精致画质的场景和云分辨率保持原设置。
- 港口坡岸使用带层理、偏心裂隙和底部内收的实体岩块，部分嵌入原地形，避开建筑、道路及起降通道；碰撞箱与实例变换一致。其他岛保留低面数岩体。
- 七类近景树冠使用有空隙的叶簇，合为一个实例绘制。远处用更轻树冠，约 185–255m 间过渡；柏树保持锥状。粗树冠投影，避免透明卡片投成方形阴影。
- 港口与小镇按实际旋转建筑占地烘焙墙脚遮蔽。只削弱间接光，随离墙距离和相对地基高度衰减，不给全岛覆盖统一暗色。
- 玩家飞机有独立 28m / 2048² RGBA8 阴影网格；原近、远地景阴影保留。精细网格只绘制飞机；静止机库可缓存。游戏和机库均接入。
- 红翼座舱三只仪表有真实安装位置、刻度、指针枢轴、玻璃反射和弱夜间照明，读取实时空速、高度及螺旋桨转速。原 HUD 布局保持。
- 红翼浮筒拉索内端收回有效蒙皮，Blender 源、GLB、侧视图和 AO 同步重新生成。

## 验证

- 近岸：`/?view=harbor&shore=1&time=noon&weather=sunny&quality=high`
- 街区：`/?view=harbor&street=1&time=noon&weather=sunny&quality=high`
- 黄昏：`/?view=harbor&street=1&time=dusk&weather=sunny&quality=high`
- 雨夜：`/index.html?aircraft=mc72&launch=1&time=night&weather=rain&quality=high`
- 红翼：`/index.html?aircraft=redwing&launch=1&time=noon&weather=sunny&quality=high`，C 切到驾驶舱，拖动向下看仪表，F 解缆、Shift 增加油门。

Chrome 1440×900、精致、固定港口近岸短样本：原版平均 29.81ms / P95 36.10ms，本轮合批后 31.81ms / P95 34.20ms。样本受浏览器和机器负载影响，不能据此承诺稳定 60FPS；新增材质仍有少量开销。完整航线及最低硬件基准待测。

自动化覆盖岩体闭合与有限法线、叶簇面数预算、旋转占地遮蔽及地基高度、仪表标定、阴影绘制范围及场景状态恢复；另运行既有任务、碰撞、海湾与机型回归测试。

最终检查：246 项测试全部通过，生产构建通过。日间街区、雨夜 MC.72、红翼驾驶舱实际 WebGL 渲染没有脚本或着色器错误，未发现缺失资源；红翼解缆加油门后实测转速 1480r/min，座舱指针同步变化。截图为实际游戏渲染：[港口街区](screenshots/visual-foundation-harbor.png)、[红翼座舱](screenshots/visual-foundation-cockpit.png)。

## 第二阶段：地形与建筑实体结构

- 港口外侧山坡增加弯曲沟槽和不规则岩层起伏，最大侵蚀约 11m；中央坡道、12m 以下低岸线、海湾和水上跑道不参与形变。仍由 `terrainHeight` 统一驱动渲染、道路贴地和碰撞。
- 建筑源模型的窗框改为四边实体窗侧墙，玻璃退入窗洞。主体墙与上层门廊墙按窗口批量布尔切凹槽，避免玻璃前仍有一整块实墙。
- 双坡屋顶增加底面和檐口收边、连续檐梁与外露椽头；沿用实例化建筑模块与现有远景 LOD。
- 重新导出 `environment.glb`、Blender 源模型和建筑腔体遮蔽。窗洞与屋檐结构同时用于港口和小镇。

第二阶段实机截图：[港口街区结构](screenshots/structural-harbor-street.png)、[港口全岛](screenshots/structural-harbor-island.png)。新增几何检查直接读取导出的 GLB：用射线验证窗洞深度，并按焊接后的边验证屋顶闭合。模型文件约 2.88MiB；近景联排住宅上限 2800 三角面，其他家族 1900，远景继续使用原简化模型。

第二阶段最终验证：250项测试全部通过，生产构建通过，实际港口近景与全岛渲染没有脚本或着色器错误。单独运行 Chrome、1440×900、精致的街区短样本约18.5FPS（平均53.98ms、P95 67.60ms），377次绘制。当前近景性能仍未达到发布目标，应继续做场景分区LOD与阴影更新预算；不能把本轮结构改进称为性能优化完成。

## 基地样板重做

- 基地外岸增加临海陡壁、低位岩台和背风缓坡。首段港区增设船坞维修滑道及绞盘铺地。植被按林地、果园和开阔地分布，减少绕岛均匀散布的岩块。
- 建筑合批保留 GLB 的 UV 和表面类别。石灰岩、抹灰、陶瓦、玻璃、木作和金属可在同批内用不同的着色参数。街区按 144 米地块和相机投影分档，远景阴影和远处倒影使用比较简洁的建筑几何。近景叶片按相机周边范围提交。
- 深海色改用连续低对比变化。浅海颜色由海床深度和底质主导。水面的镜面纹理根据已模糊的采样去掉重复的多重采样开销。精致档实测场景比例为 1.000。

Chrome 1440×900 精致档固定镜头短样本，场景预热后按相同条件采样。以下帧时间包含呈现开销，测试不是整段飞行的平均成绩。

## 基地返场与着水

- 普通飞行区分空速和地速，风速来自天气强度及阵风。起飞条件用沿机头方向的相对气流，空中位移用对地速度。滑行、救援和靠泊按水面移动速度判定。
- 接水判定记录实际先接触的船体或浮筒，并用该处浪面的垂直速度评估撞击。滑水时船体轻微升起，尾迹收窄。触水处发出不规则泡沫和水花，双浮筒分别响应。
- 港口风向袋、帆船主帆、短浪和雨线使用共同的西北来风。港灯水面高光随观察角度和浪面法线变化。发动机音效由桨轴实际转速驱动，座舱中对高频桨声作衰减。
- 静态地景阴影复用贴水飞行时相邻帧的已有阴影图。飞机仍有独立阴影图。精致档继续用原生分辨率。

Chrome 实飞验证覆盖清晨晴天、黄昏多云和夜间晴天三种条件。黄昏中央水道从坐标 `(-2460, 28.05, 2620)` 向北进近，约 4.32 m/s 的西北风，使用实机飞行物理和标准靠泊判定，约 59 秒模拟时间后系泊于基地栈桥。三组均成功着水，黄昏中央水道跑完滑行与靠泊。

上述为 1440×900 精致档动态片段。最后进近约 17–21 FPS，黄昏中央水道进入港内后 P95 仍可达约 90 毫秒。该片段与上一阶段固定视角测试的镜头不同，不能直接用于计算性能增益。
